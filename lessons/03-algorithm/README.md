# الدرس 3: Algorithm

قبل ما نكتب Code، لازم نفهم يعني إيه Algorithm.

## في الدرس ده
- Hardware وSoftware
- يعني إيه CPU وRAM وStorage
- الفرق بين المشكلة وفكرة الحل وخطوات التنفيذ
- يعني إيه Algorithm: طريقة محددة من خطوات واضحة لحل مشكلة
- ليه ترتيب الخطوات مهم
- إزاي نعرف إن الـ Algorithm واضح وبينتهي ويوصل للنتيجة المطلوبة (في الأمثلة البسيطة)
- الفرق بين الـ Algorithm والـ Program

## التمرين
اكتب Algorithm يوصّل صاحبك من محطة مترو لمكتبة. الأماكن خيالية فاخترع الطريق.

الدرس ده من غير كود.
