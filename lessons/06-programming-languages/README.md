# الدرس 6: Programming Languages و Source Code

الفيديو: https://youtu.be/nDNcmwz5jqo

الكمبيوتر مش بيفهم لغتنا العادية ولا Python بشكل مباشر. في الدرس ده نفهم الكمبيوتر بيفهم إيه، ونعرف الـ Programming Language والـ Source Code.

## في الدرس ده
- الكمبيوتر بيفهم إيه؟ يعني إيه Binary و Bit و Byte
- جدول ASCII: إزاي الحروف بتتحول لأرقام
- يعني إيه Programming Language وليه بنحتاجها
- يعني إيه Source Code، والفرق بينه وبين الـ Programming Language والـ Pseudocode
- نظرة سريعة على لغات زي Python و JavaScript و C++
- تمرين

## مثال
```
print("Hello World")
```
السطر ده Source Code مكتوب بلغة Python. كلمة print معناها اعرض، والبرنامج هيعرض الجملة Hello World على الشاشة. الأقواس وعلامات التنصيص هنشرحها في درس print.

2. لو عندك السطر ده، إيه اللغة المستخدمة؟ وإيه الـ Output المتوقع؟

print("Welcome")
