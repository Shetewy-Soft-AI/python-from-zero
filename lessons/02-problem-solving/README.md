# الدرس 2: Problem Solving

إزاي المبرمج بيحلل المشكلة ويقسمها لخطوات صغيرة ويجرب الحل.

## في الدرس ده
- يعني إيه Problem وProblem Solving
- إطار مبسط من أربع خطوات للبداية (مش حل سحري لكل المشاكل): افهم المشكلة، حدد الـ Input والـ Output، قسّم الحل لخطوات، وجرّب بأرقام حقيقية
- مراجعة تمرين ATM
- مثال: أعلى درجة في قايمة درجات، خطوة بخطوة
- Logical Thinking وترتيب الخطوات
- نفس الخطوات على مشكلة قريبة: أقل درجة في القايمة

## التمرين
اكتب الـ Input والـ Output وخطواتك لحساب سعر منتج بعد خصم 10%.

الدرس ده من غير كود.
