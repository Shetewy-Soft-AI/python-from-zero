# الدرس 1: What is Programming

هنفهم يعني إيه برمجة وإزاي الكمبيوتر بينفذ التعليمات، من غير أي خبرة سابقة.

## في الدرس ده
- الفرق بين Programming وInstructions وProgramming Language
- Input → Process → Output، بمثال كوباية الشاي وجمع رقمين: 5 + 3 = 8
- أهمية صحة الخطوات وترتيبها
- أمثلة لاستخدام البرمجة في تطبيقات الموبايل والمواقع والألعاب والذكاء الاصطناعي
- خريطة السلسلة

## التمرين
حدّد المدخلات والمعالجة والمخرجات لعملية سحب فلوس من ماكينة ATM، ورتّب خطواتها.

الدرس ده من غير كود.
