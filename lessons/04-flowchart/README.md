# الدرس 4: Flowchart

هنحول خطوات الـ Algorithm من كلام مكتوب لرسم واضح اسمه Flowchart.

## في الدرس ده
- يعني إيه Flowchart وإيه علاقته بالـ Algorithm
- الأشكال الأساسية: Terminator, Input / Output, Process, Decision, Arrow
- رسم مثال خصم 10% خطوة بخطوة (من الدرس 3)
- يعني إيه Decision وإزاي تمشي في مسار Yes أو No (خصم لو السعر 100 أو أكتر)
- تمرين: Flowchart لمشوار المترو للمكتبة، مع حل مقترح

الدرس ده من غير كود.
