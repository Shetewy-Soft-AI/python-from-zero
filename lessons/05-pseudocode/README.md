# الدرس 5: Pseudocode

الفيديو: https://youtu.be/qIZgCwMRMjI

بدل ما نبدأ نكتب Code على طول، بنكتب خطوات الحل الأول بتعليمات بسيطة ومنظمة اسمها Pseudocode.

## في الدرس ده
- يعني إيه Pseudocode وليه بنكتبه قبل الكود
- الفرق بين Algorithm و Flowchart و Pseudocode (نفس مثال الخصم من الدرسين 3 و 4)
- الكلمات الأساسية: START, INPUT, OUTPUT, IF, THEN, ELSE, END
- IF و ELSE في الـ Pseudocode وربطهم بالـ Decision في الـ Flowchart
- نصايح كتابة الـ Pseudocode وحل تمرين الدرس 4
- تمرين: Pseudocode لبرنامج يعرض Pass أو Fail حسب الدرجة

## مثال الخصم بـ Pseudocode
```
START
INPUT Price
IF Price >= 100 THEN
    Discount = Price * 10%
    FinalPrice = Price - Discount
ELSE
    FinalPrice = Price
OUTPUT FinalPrice
END
```

الدرس ده من غير كود.
